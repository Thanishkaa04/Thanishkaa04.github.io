Biorobotics Lab · UW · Jan 2026 – Present

Real-time lane tracking & adaptive assist

A closed-loop 1-D path-tracking testbed for studying how people and machines share control. Participants steer a plant along a prime-frequency sum-of-sines reference while first- or second-order dynamics are integrated with RK4. The same protocol runs on a trackpad, USB slider, and Novint Falcon haptic device.

  • 60 Hz real-time loop with overrun diagnostics
  • 60+ human trials logged for RMS error, effort, and FFT validation
  • Normalized LMS adaptive helper with game-theoretic LQ framing

Raw Falcon position mixes human and machine motion, so I built a calibrated spring-damper predictor to recover the human contribution, then estimate the human control policy from observed actions with least-mean-squares gradient descent. Assist gains are bounded so the helper stays stable and physically safe.

Bair Lab · UW Neurobiology & Biophysics · Mar 2024 – Present

Cortical maps, Suite2p, and ViT color sensitivity

In the Bair Lab I studied visual selectivity in macaque V1 from two-photon calcium imaging with Prof. Wyeth Bair. Combining two Suite2p segmentation regimes recovered about 15% of missed ROIs across 1,000+ neurons. I then fit 100+ tuning curves with SciPy and mapped size preference. Neurons that prefer smaller targets tended to cluster in cortex.

View the GitHub repo ↗

My current project compares that biology to deep networks. I compute a Color Sensitivity Index (CSI / CRI) for Vision Transformer patches across all 12 encoder layers. I am extending this to fill out line invariance and comparing all of this to AlexNet and biological neurons.

  • 196 ViT-B/16 patches (14×14 grid on 224×224)
  • 12 encoder layers, full and partial networks
  • Patch 91 used as a reference for layer-wise histograms and spatial dropoff

Independent project · Apr 2024 – Jun 2025

Real-time EEG confusion classifier

A full-stack BCI demo that streams 11 EEG band-power features over WebSockets and runs five models in parallel to predict whether a student is confused while watching lecture video. Models were trained on 12,000+ samples; engineered Theta/Beta and Theta/Alpha ratios improved discrimination over raw band powers.

  • 79.36% validation accuracy: Random Forest, ~2 ms
  • 5 concurrent models: RF, NN, RNN, ResNet, CNN-RNN hybrid
  • React + FastAPI dashboard for confidence, latency, and agreement

The UI lets you pick a subject and video topic, control stream speed, and watch each architecture vote 0 (not confused) or 1 (confused) with live confidence. A schema-validated API also accepts uploaded EEG files for offline analytics. The repo is set up so you can clone it from GitHub and run the full demo locally.
