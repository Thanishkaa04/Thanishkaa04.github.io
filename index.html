Biorobotics Lab · UW · Jan 2026 – Present

Real-time lane tracking & adaptive assist

This is a closed-loop 1-D path-tracking testbed for studying how people and machines share control. Participants steer a plant along a prime-frequency sum-of-sines reference while first- or second-order dynamics are integrated with RK4. The same protocol runs on a trackpad, USB slider, and Novint Falcon haptic device.

  • The real-time loop runs at 60 Hz with overrun diagnostics.
  • I logged 60+ human trials for tracking error, control effort, and frequency-domain analysis.
  • An adaptive helper uses normalized LMS with a game-theoretic LQ framing.

Because Falcon position reflects both user input and machine-applied motion, I built a calibrated predictor to estimate the machine contribution and recover the human command used for online policy estimation. The recovered command feeds the LMS-based human-policy estimator, while bounded assist gains limit unstable or excessive helper behavior.

Bair Lab · UW · Mar 2024 – Present

Cortical maps, Suite2p, and ViT color sensitivity

In the Bair Lab I studied visual selectivity in macaque V1 from two-photon calcium imaging with Prof. Wyeth Bair. Combining two Suite2p segmentation regimes recovered about 15% of missed ROIs across 1,000+ neurons. I then fit 100+ tuning curves with SciPy and mapped size preference. Neurons that prefer smaller targets tended to cluster in cortex.

View the GitHub repo ↗

My current project compares that biology to deep networks. I compute a Color Sensitivity Index (CSI) for Vision Transformer patches across all 12 encoder layers. I am extending this analysis to fill-out line invariance and comparisons with AlexNet and biological neurons.

  • I analyze 196 ViT-B/16 patches on a 14×14 grid at 224×224.
  • The comparison covers all 12 encoder layers in full and partial networks.

Independent project · Apr 2024 – Jun 2025

Real-time EEG confusion classifier

This is a full-stack BCI demo, built with React, FastAPI, and WebSockets, that predicts whether a student is confused while watching lecture video. Models were trained on 12,000+ samples with a 36-feature preprocessing and feature-engineering pipeline. Engineered Theta/Beta and Theta/Alpha ratios improved discrimination over raw band powers. The live deployment streams 11 of those features over WebSockets and runs five models in parallel.

  • The best validation accuracy is 79.36%.
  • The demo runs 5 concurrent models: Random Forest, NN, RNN, ResNet, and CNN-RNN.
  • Random Forest inference latency is about 2 ms.

The UI lets you pick a subject and video topic, control stream speed, and watch each architecture vote 0 (not confused) or 1 (confused) with live confidence and its own latency. A schema-validated API also accepts uploaded EEG files for offline analytics. The repo is set up so you can clone it from GitHub and run the full demo locally.
